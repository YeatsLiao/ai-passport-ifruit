# 当前版本与验证

2026-11-12 项目收尾版本。固件面向 FoloToy AI Passport 的 ESP32-C3，完整镜像为 8MB。使用方法见[项目 README](../README.md)。

## 本轮结果

- 使用 ESP-IDF 5.5.5 从 `firmware/` 工程构建，直接读取 `firmware/resources/` 中的设备资源。完整镜像的引导、分区表、应用和音频均按烧录地址逐段核对。
- 主机状态机、通信与存档往返、WAV 解析通过。校验了 1,106 项素材和 143 个设备输入文件的索引与哈希。
- 三种皮肤使用实际 LVGL 代码完成预览，固定 32KB 内存池和 120 轮切页、来电打断测试通过。README 中的图片来自此类主机预览。
- 5 项截图协议测试通过。本轮实机烧录及三键、音频和截图联调待现场复测。

## 容量与产物

应用占 3,053,552 字节，应用分区余 92,176 字节。135 个设备音频共 3,054,258 字节，距 4MiB 保守预算还余 1,140,046 字节。该预算用于资源打包，设备 SPIFFS 的实时空闲量需在设备上查询。

完整包为 `firmware/build/ai-passport-ifruit-full.bin`，文件字节数、SHA-256 和分区余量记录在 `firmware/build/release.json`。普通更新与首次完整烧录的区别见[开发与素材更新](development.md)。
