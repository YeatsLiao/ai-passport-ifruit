## 构建

## 真机首测反馈：背光未开启

2026-11-07 用户实机日志显示屏幕与 LVGL 初始化继续执行，但屏幕全黑；同时 SPIFFS mount failed -10025。检查 BSP 确认 backlight_init 将 LEDC duty 设为 0，应用此前未调用 bsp_display_backlight。这是代码中的明确背光遗漏，主机渲染无法验证实体背光。

修复：创建首屏后开启 75% 背光；LVGL 初始化移出断言表达式，首次 UI 锁定不再静默跳过；新增 UI created / backlight / heap 日志。音频挂载失败仍允许 UI 启动，并新增分区刷写提示，不自动格式化。

本机 SPIFFS 镜像参数与固件一致，flash_args 包含 0x310000 assets.bin。用户设备上挂载失败的具体原因尚未确认，先要求使用包含素材镜像的完整 flash 流程；不执行 erase-flash。背光修复的实机复测结果待用户确认。
