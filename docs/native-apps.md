# Snapmatic、剧情来电和拨号盘

## Snapmatic

桌面相机图标是原版图集裁切，不是自绘。现在菜单只保留 Take photo (demo) 与 View photos：取景器上下切换预制画面，OK 快门进入确认页，再按 OK 保存；长按 OK 取消并回到取景器。相册只显示已保存的图片，空相册没有可执行的确认按钮；查看相册图片时上下浏览保存的照片，长按返回。

演示画面包括 Michael、Franklin、Trevor 和 Los Santos。三主角使用本地 loadingscreen5、loadingscreen1、loadingscreen9 的高分辨率原始前景与配套背景，为设备重新取景；城市图来自原版城市背景。它们是游戏原版载入插画，不是通讯录小头像放大，也不是游戏相机实拍。没有硬件摄像头输入，因此不将演示描述为真实拍摄。

全部照片以 240×216 输出，避免运行时放大。保存只记录图片编号，不改变壁纸；snap_v1 独立保存三角色相册位图，不再把旧的壁纸捕获标记当照片展示。普通更新保留 state_v4、comm_v1 等旧存档。旧壁纸标记仍留在原存档中，没有当作新照片迁移。

## Story Calls

桌面右下角使用三种手机皮肤各自的原版未接来电图形。上下选择当前主角的来电，OK 触发来电画面，再按 OK 接听原声。播完、拒接、挂断或响铃超时都会回到选中的条目。条目标题根据对白整理，手动回放独立于剧情任务和通信记录。

## Dial Pad

通讯录长按上键打开拨号盘。上下键选号码，OK 拨出。列表置顶 Downtown Cab Co.（323-555-5555）和 Enter a number，其余号码随主角通讯录切换。号码取自 Legacy 的角色注册脚本及本地文本档案。

手动拨号时，上下键按从左到右、从上到下的顺序移动，OK 输入数字或选择 Erase、Call，长按 OK 返回。未知号码显示忙线，派车回执会标为本地模拟。

三位主角各有一通原版出租车电话，包含主角叫车、接线员确认、主角回应。素材来自 Legacy 的 taxilauncher.ysc、TAXISAU 和 taxis.awc，逐句记录见 assets/catalog/taxi-calls.json。播放结束后设备发派车短信。原版黑手机号码会切换本次开机的深色主题。

## 资源与容量

原始 GFX、YTD、脚本和载入图保存在 assets/ui、assets/icons；来源、哈希与权利状态进入 manifest.json，帧与场景说明见 assets/catalog/native-apps.json。Trackify 原件保留，设备镜像不再打包雷达转换资源。

设备提供 10 张壁纸。旧存档选中的壁纸未装入当前设备包时，会回退到角色默认壁纸。

最新容量、构建和验收情况见[验证状态](verification.md)。
