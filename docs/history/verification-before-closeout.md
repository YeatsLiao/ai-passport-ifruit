# 验证状态

当前结果以 build/release.json 的产物哈希与容量为准。历史交付说明里的数字属于相应批次。

## 已完成的检查

- 状态机：导航、来电、拨号等待、对白结束、忙线、任务、设置与边界。
- 存档：NVS 往返、64 位已读状态、照片、彩蛋与异常数据回退。
- 素材：1097 个登记素材的路径、哈希与 PCM 元数据；设备 WAV 解析、原版程序拨号音及角色音效读取检查。
- 实际 LVGL：三角色主要页面和正文，无桌面缩放动画检查、固定竖屏、120 轮切页/来电打断。Release 预览显式启用 C 断言，固定 32KB 池最后余 4952 字节，碎片 19%，连续空闲块检查通过。
- ESP-IDF 5.5.5：目标 ESP32-C3 构建通过；本次另用独立构建目录验证 firmware/ 设备输入和完整镜像合并，通过；已逐段比对完整镜像中的引导、分区表、应用和音频字节，并核对 140 个设备输入文件哈希。

## 容量与产物

应用约 3MiB，剩余空间很少；详细字节数见 build/release.json。132 个设备音频共 3,033,370 字节，4MiB 保守音频预算余 1,160,934 字节。该预算不是对设备 SPIFFS 实际空闲空间的查询。

完整烧录包含 bootloader、partition-table、ai-passport-ifruit.bin 和 assets.bin。合并文件按整个 8MB Flash 填充，烧录到 0x0 会覆盖包括 NVS 在内的完整范围。日常保留存档应使用 idf.py flash；正常更新不需要 erase-flash。

## 仍需实机验收

本批未对连接设备下发烧录。需要实机检查启动、屏幕色彩、铃声和拨号音音色、音量/亮度、快速按键与对白播放中挂断、保存后重启。

截图是主机 LVGL 实际渲染，不是实机照片。保留三键适配、英文剧情档案、240×320 竖屏、离线任务/资金/相机演示，以及固定 3 秒接通等待。原始合成程序通过离线 DSP 重建，不宣称与游戏引擎输出逐样本一致。

通信扩充：原版 39 通来电、36 段好友邀约分支、35 位答录机，共 110 个压缩对话流通过读取检查；新增通信存档、回拨、关联短信、冷却和旧铃声设置迁移检查通过。默认头像已补齐，通信与任务消息不会因未知发件人缺少默认头像。当前流程及模拟边界见 communications.md。

Snapmatic 与 Trackify 的当前实现以 native-apps.md 为准。默认相册标记独立于壁纸，拍照保存/取消及空相册检查通过；原版蓝色雷达和三主角照片预览通过，壁纸由 15 减为 10，旧选择可回退。
