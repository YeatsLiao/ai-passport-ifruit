# 默认铃声与角色皮肤 · 2026-11-10

已完成接入、桌面实际LVGL渲染、播放读取检查及ESP32-C3目标构建。本批未烧录、未完成实机试听。

## 外观与操作

角色切换会自动换皮肤：Michael保持iFruit；Franklin使用原版Badger图标、默认壁纸与绿色界面；Trevor使用原版Facade图标、红色磁贴、黑色页面和原版裂纹玻璃层。图标矩形来自原GFX帧标签、形状边界和纹理矩阵，未猜图集网格。所有页面按角色切换颜色；原有阅读、电话、任务、相册和设置功能保留。

为控制Flash与RAM，新增图标转为40px、Badger默认壁纸120×112放大显示、裂纹120×60放大显示；这是240×320设备适配，不宣称完全复刻原版字体、Scaleform动画和每个页面坐标。原始PNG/YTD/GFX和脚本放在assets的浅目录，转换文件放build/generated；来源矩形见assets/phone-skins.json。

Settings → Ringtone 中Ringtone 1/2/3现在可试听并用于来电，Silent仍静音，原有9段Original clip仍保留。新增Character default选项：Michael→1、Franklin→2、Trevor→3，随角色自动选择。新初始化使用此选项；保留旧存档铃声选择，旧用户需手动选一次Character default。设置里的Theme第一个选项显示Character default，角色分别使用蓝/绿/红；其余主题可继续选择。

## 铃声来源与准确性

全部素材取自本地Steam GTA V Legacy，游戏文件只读。sounds.dat54.rel中的PHONE_GENERIC_RING_01/02/03追到optamp.dat10.rel的原始合成程序e9e42095、df4f0b6b、54079c4c。Trevor还组合RESIDENT/frontend.awc的波形152c8678（逐哈希确认的第76流），保留两次500ms重触发、450ms保持/50ms尾音、100ms停顿与-12dB合成层。

使用[CodeWalker官方合成器实现](https://github.com/dexyfex/CodeWalker/blob/master/CodeWalker/Utils/Synthesizer.cs)离线生成，设备只播放生成WAV，没有在ESP32运行游戏合成引擎。原版程序、时序及录音层可追溯；CodeWalker的部分DSP滤波/包络实现尚有待核对项，所以应称原版程序的离线重建版，不宣称与游戏引擎逐样本相同。元数据、来源和渲染器哈希见assets/native-ringtones.json，原始REL另保存在assets/ui/gta_phone_*.rel。

重建入口为tools/render_phone_synth.py（依赖build/tooling的官方源码及build/reference的只读导出）。铃声按16kHz单声道PCM打包，长度约2.508/2.513/1.100秒，循环播放时保留原序列间隔。

## 烧录与实机验收

```bat
idf.py -DIFRUIT_PACK_AUDIO=ON build
idf.py -p COM5 flash monitor
```

替换实际串口；必须完整烧录素材分区，无需erase-flash。先确认三个角色皮肤及返回，再在Ringtone里依次试听1/2/3、Silent及Character default，桌面双击OK测试来电循环与挂断停止。检查音量0/中/最大并连续切换试听；本批无需清除旧NVS存档。
