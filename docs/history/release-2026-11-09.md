## 容量与验证

100个设备WAV共3,283,078字节（约3.13MiB），4MiB音频安全预算余911,226字节（约0.87MiB）。这是打包预算余量，不是实机SPIFFS查询的剩余容量。对白用8kHz GSM/WAV49，铃声和短音效保留PCM；电脑原始素材未修改。

固件2,886,144字节，3MiB应用分区余259,584字节（约253.5KiB，8%）。assets.bin 是完整0x4f0000镜像，写入0x310000；完整产物哈希见 build/release.json。

状态机验证覆盖12段主动拨号方向、Call/Hang Out分离、取消、重复消费、余额不足、重复任务奖励；NVS验证保存交易和高位未接事件、读写去重/失败/坏版本、v3和早期存档迁移。955条素材来源/哈希检查通过。86个压缩电话/答录机文件通过真实WAV读取器流式解码，一通完整电话样本与FFmpeg参考一致。实际LVGL用固定32KB池遍历三角色全部正文及新页面，剩6824字节、碎片3%。ESP-IDF目标构建通过。

这些检查不代替实机扬声器、实体按键和连续运行测试。三角色仍共用当前iFruit开发外观；Franklin/Trevor原手机皮肤、默认合成铃声、完整原版网站布局尚未完成。相机为壁纸模拟。

## 烧录

在本工程的ESP-IDF终端执行：

```bat
idf.py -DIFRUIT_PACK_AUDIO=ON build
idf.py -p COM5 flash monitor
```

COM5替换成实际串口；必须完整烧录含assets.bin的工程，无需erase-flash。state_v4兼容读取state_v3和早期设置/任务存档；虚拟账户首次初始化不追溯发放旧任务奖励。

实机依次检查：音量/亮度预览和取消 → 铃声试听 → 三角色Hang Out各一通及中途挂断 → Jimmy接听/拒接 → 任务完成与余额变化 → 捐款确认/取消 → 重启检查进度。
