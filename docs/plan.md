# iFruit 执行计划 · 2026-11-07

用户要求：从本机 GTA V Legacy 提取 iFruit 原版素材，按游戏功能和操作感还原。游戏世界相关部分本地模拟；第三方网友网站不作为准确性依据。硬件固定为 AiPassport，不开发硬件，不增加生活工具功能。

## 已完成的基础

- REA 6.8.0 独立 Node 24.22.1 环境安装、CLI 验证、Codex 注册；本会话使用 CLI，未建立 MCP 连接。
- Steam 安装清单显示下载完成，读取 GTA5.exe 版本 1.0.3889.0 并记录 SHA-256；不是 Steam 完整性验证结果。
- 基础/更新 RPF 索引与只读解包；更新归档中的同名资源优先。
- 213 个手机相关原始界面/纹理资源、268 张解码图片入库；原版 UI ActionScript 和原生脚本分析流程打通。
- 原版铃声包、9 段铃声、麦克的 4 段界面音效、答录机包及 115 段语音入库。答录机角色/字幕/触发映射待核对。
- ESP32-C3 固件、三键输入、独立音频任务、SPIFFS、原版图片转换、主机测试和 LVGL 预览流程。

## 当前实现与缺口

桌面故事模式顺序、初始选择联系人、条件 Trackify 已按原生脚本设置。联系人、来电和通话画面已接原版头像，名单仍是开发子集。麦克导航、确认、返回音效已接入，短信音已准备但尚无到达事件。

新增设置五个故事模式入口，支持 15 张原版背景、7 套原版配色，以及 Normal/Sleep Mode。铃声选择和 Vibrate 状态可操作，铃声合成器与实体振动未实现；设置已接入 NVS 保存，确认后写入；实体断电验收待做。

115 个答录机流已对应到 ANAUD 音频名称，解析出 76 组相关对话标签。Lester / LES_APH2、Amanda / AMA_APH1、Dave / DAV_APH1 的身份、原文、声音流已核对并接入拨号→原声→结束返回。固定 3 秒拨号和未绑定联系人的 BUSY 是本地演示设置，不声称为游戏任务时序。答录机结束合成提示音暂缺；Jimmy 的三段对白和间隔已解析，尚未接入序列器。

邮件、短信正文、检查清单、快速存档、Snapmatic、互联网、Trackify 仍只有入口或占位。默认铃声确认名为 PHONE_GENERIC_RING_01，涉及游戏合成器，不是从 9 段导出铃声随意挑选。

## 下一阶段：内容与模拟

1. 从原生手机应用脚本与文字库核对原版标签、菜单层级、选项、软键和返回行为；补齐字体、状态栏、选中态与页面布局。
2. 建立一份平铺的本地事件内容清单，记录每个事件的原版脚本/文字键/声音流出处与时间顺序。先完成一条角色、声音、字幕均已核对的拨号/来电闭环，再扩展联系人。未核对录音不绑定人物。
3. 邮件/短信使用游戏原文和发送者；本地事件模拟收到、未读、阅读和返回。内容与渲染分开。
4. 原版设置驱动本地壁纸/铃声/主题；快速存档保存本地演示进度；检查清单使用一组固定剧情状态。
5. Snapmatic 以原版图片模拟取景、快门和图库；互联网先做原版站点的精选离线页面；Trackify 通过固定场景模拟信号变化。上述是待实现方案，不是已完成功能。
6. 逐页和原版实际运行画面对照，记录三键与 240×320 屏幕适配差异。原版 GFX 为 256×344，不能直接宣称像素一致。

## 真机验收

构建通过后，确认连接设备/串口再烧录。检查连按、长按、声音切换、铃声循环、挂断尾音、音量、语音速度、缺失文件处理、长期运行和堆余量。原件与 16kHz 设备版需对照试听。

8MB Flash 不能直接装入全部游戏语音。电脑素材库保留完整已提取内容，设备根据已验证场景精选；图片转换和音频转换均放 build，不覆盖素材原件。完整性按资源范围分别报告，不把目前的中央手机包当作已找全所有网页、字体和任务对话。
